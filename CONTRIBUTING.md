# Contributing research, not speculative pinouts

Before submitting an issue or pull request, read [bench/legal/safety](docs/04-legal-safety.md). By contributing you confirm that you have rights to share original descriptions, code and sanitized data.

- Identify exact assembly, side, revision, supplier, region and whether laser hardware is present. Do not post VIN/registration or identifiable photographs.
- Mark every technical observation **Confirmed (primary)** / **Likely (secondary)** / **Speculative (hypothesis)**. Link an evidence source, capture provenance (without personal data), and a falsification experiment.
- No OEM proprietary firmware, calibration, keys, passwords, private wiring databases, bypass recipes or undocumented authenticated responses.
- No in-vehicle exploitation, public-road experiments, harsh optical exposure, unbounded ID injection, thermal or fault-protection bypass.
- Favor small tests, neutral labels and reproducible negative results. Every data change needs a source or is marked unknown.

## PR checklist

- [ ] Linked an issue and test plan
- [ ] Identified physical variant and data provenance or marked unknown
- [ ] Preserved physical and protocol safety gates
- [ ] Removed sensitive IDs and copyrighted material
- [ ] Added or ran offline tests
- [ ] Updated source ledger and status table
